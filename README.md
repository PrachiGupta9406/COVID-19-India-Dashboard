# COVID-19 India Dashboard

## Project Overview

Created a Tableau dashboard to visualize and analyze COVID-19 cases, vaccinations, testing labs, and state-wise statistics across India.

## Tools Used

* Tableau
* Excel
* Data Visualization

## Key Insights

* State-wise Case Analysis
* Vaccination Progress Tracking
* Testing Lab Distribution
* Recovery and Death Trends
* Age & Gender Analysis
